# Manager Football

Projeto de estudo e implementação de um Manager de Futebol.

## Objetivo

Construir um Manager de Futebol enquanto aplicamos, de forma prática e incremental, conceitos e ferramentas utilizados em projetos reais de software.

O projeto prioriza entender o problema antes de introduzir ferramentas ou padrões, evitando componentes sem uma responsabilidade real.

## Estado atual

A documentação de produto e arquitetura está consolidada.

O projeto está na fase de preparação da base de implementação.

A construção será feita incrementalmente, seguindo o Mapa Mestre de Implementação e o Manual de Implementação.

## Documentação

A documentação do projeto está localizada em `docs/`.

A hierarquia documental é:

1. documentos oficiais;
2. Mapa Mestre de Implementação;
3. Manual de Implementação;
4. código existente.

Em caso de conflito, a fonte superior deve prevalecer.

O Manual de Implementação é um documento vivo e será atualizado conforme cada bloco do projeto for executado.

## Estrutura de desenvolvimento

O projeto será construído em pequenos blocos funcionais.

Tecnologias, serviços e padrões só serão introduzidos quando existir uma responsabilidade real que justifique seu uso.

Os comandos necessários para executar, testar e desenvolver a aplicação serão adicionados a este README conforme essas capacidades passarem a existir.
